# Instituto C&T

Site institucional estático em HTML, CSS e JavaScript. Abra `index.html` em um navegador para visualizar o site. Os estilos, o menu e as imagens funcionam com arquivos locais.

## Publicação

Envie `index.html`, `styles.css`, `script.js` e a pasta `assets/` para a raiz do site. No GitHub Pages, selecione a raiz da branch de publicação. No Cloudflare Pages ou Netlify, use a pasta do projeto como diretório de saída, com o comando de build em branco.

Depois de definir o endereço público, ajuste os metadados no `<head>` de `index.html`:

- Em `og:image`, indique a URL HTTPS absoluta de `assets/instituto-ct-social.jpg`.
- Adicione `og:url` com a URL HTTPS da página inicial.

O site usa fontes do sistema e inclui título, descrição e conteúdo semântico para indexação. A imagem de compartilhamento tem 1200 × 630 pixels.
